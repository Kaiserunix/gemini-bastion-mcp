Defense-in-Depth

6-Layer Security & Blast-Radius Guardrails

Engineered so you can safely connect Web AI clients to real GitHub repositories, Cloudflare accounts, and internal infrastructure.

🔒 1. Zero Gateway Secret Leakage

buildSandboxedEnv() strips GH_TOKEN, CLOUDFLARE_*, OAUTH_SIGNING_SECRET, and ADMIN_PASSWORD_HASH from all workspace subprocesses. SecretScrubber redacts credentials across all MCP outputs, logs, artifacts, and webhooks.

🧱 2. Linux Dual-UID Isolation

In Docker production, gateway runs as UID 1001 owning /data (mode 0700 SQLite WAL DB & artifacts), while workspace commands and Codex execute as UID 1002 (worker) with zero access to /data.

⏪ 3. Non-Destructive GIT_INDEX_FILE Snapshots

Before every code_patch or codex_write run, the gateway snapshots tracked and untracked files into refs/mcp-checkpoints/* using a temporary GIT_INDEX_FILE without touching your real .git/index or HEAD.

🚦 4. Main-Branch Block & Two-Phase Mutations

Direct pushes to main, master, or default_branch are physically rejected. Cloudflare and downstream MCP-2 mutations must be staged via stage_mutation_plan (15m TTL + rollback payload) before publish_changes executes them.

🛡️ 5. Untrusted Content Boundary

External text from github_inspect (PR bodies, comments, Actions logs) and infra_inspect (Worker tail logs, downstream MCP output) is wrapped in explicit untrusted-data boundaries to resist indirect prompt injection.

🔑 6. OAuth 2.1 Token Family Theft Detection

Implements PKCE (S256), RFC 8707 Resource Indicators, and refresh token family rotation with a 60-second grace window for concurrent retries — revoking the entire family immediately on post-grace replay.

Deploy & Connect

3-Minute Quick Start

Generate a Docker-Compose-safe scrypt password hash, launch the container stack, and paste your /mcp endpoint into Web Gemini, Claude.ai, or ChatGPT.

1. Generate Operator Password Hash (scrypt:<salt>:<hex>) & Signing Secret

node -e 'const c=require("node:crypto"),s=c.randomBytes(16).toString("hex");console.log(`ADMIN_PASSWORD_HASH=scrypt:${s}:${c.scryptSync(process.argv[1],s,32,{N:16384,r:8,p:1}).toString("hex")}`)' 'your-strong-operator-password'
node -e 'console.log("OAUTH_SIGNING_SECRET=" + require("node:crypto").randomBytes(32).toString("hex"))'

2. Configure .env & Start Docker Compose Stack

git clone https://github.com/Kaiserunix/gemini-bastion-mcp.git
cd gemini-bastion-mcp
cp .env.example .env
# Edit .env: set PUBLIC_DOMAIN, ADMIN_PASSWORD_HASH, OAUTH_SIGNING_SECRET, GH_TOKEN, etc.
docker compose -f docker/docker-compose.yml up -d --build

3. Connect Web Gemini (gemini.google.com), Claude.ai & ChatGPT

# MCP Streamable HTTP Endpoint (OAuth 2.1 DCR auto-discovers /.well-known/*):
https://mcp.yourdomain.com/mcp
